# Project Examples

This directory is a public, Git-tracked presentation snapshot of four complete KnowledgeOS projects. It contains Human-facing canonical documents only: project orientation, solution reconstruction, solution-space synthesis, and focused deep dives.

The local `vault/` remains the durable working knowledge layer. Primary evidence, source captures, repository metadata, and Research Run machine state remain outside this showcase so this folder is not a competing source of truth.
